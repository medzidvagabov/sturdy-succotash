САЙТ ПРОЕКТА «ПОМОГАЛКА» — многостраничная версия
==================================================

СТАРТ: откройте index.html в браузере (двойной клик). Весь сайт статический —
никакой сборки и установки не требуется. Можно бесплатно выложить на
GitHub Pages / Netlify / Vercel целиком (папку pomogalka-site).

СТРАНИЦЫ
  index.html    — лендинг проекта (проблема, цели, этапы, бюджет, команда, FAQ)
  how.html      — «Как это работает»: роли, шаги, правила честности, цена баллов
  login.html    — вход/регистрация + все демо-аккаунты в один клик
  cabinet.html  — личный кабинет (вид зависит от роли: студент / наставник / админ)
  admin.html    — админ-панель: дашборд, пользователи, запросы, антифрод,
                  аналитика, бонусы (доступна только админам/модераторам)
  assets/       — общий стиль (css/style.css) и данные платформы (js/data.js)

КАК ПОСМОТРЕТЬ ВСЁ ЗА 2 МИНУТЫ
  1) login.html → клик по карточке «Камила Салихова» → админ-панель
  2) в разделе «Антифрод» закройте флаг со списанием баллов
  3) выйдите, на login.html кликните «Полина Смирнова» → создайте запрос
  4) выйдите, войдите как «Артём Кузнецов» → возьмите запрос на доске,
     отправьте на подтверждение, обменяйте баллы на бонус
  5) войдите как «Полина Смирнова» → «Подтвердить помощь» →
     у Артёма появятся +40 баллов

СОХРАНЕНИЕ ДАННЫХ
  Действия (запросы, баллы, блокировки, регистрации) хранятся в localStorage
  вашего браузера и переживают перезагрузку страницы. Кнопка «Выйти» не
  сбрасывает данные; полный сброс — очистка localStorage для сайта.
